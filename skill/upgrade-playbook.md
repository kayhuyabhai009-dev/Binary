## 2. Fixes — Editing & Production (Editing Skill Upgrade)

### 2.1 Visual Differentiation (W8 fix)
1. **Signature visual motif banao** — har video mein ek recurring transition (e.g., "vault door wipe" ya "ink dissolve") = brand recognition
2. **Custom AI style lock** — ek fixed Midjourney style suffix (e.g., "dramatic documentary photography, teal shadows, amber rim light") har image prompt mein — consistent look like Vox/Neo
3. **3D diagram explainers** — original mostly stock+images use karta hai; tum animated 3D-ish diagrams (After Effects/CapCut) banao — "hydrostatic trap" jaise concepts 10x better dikhenge
4. **Archival authenticity** — history segments mein grain + timestamp overlay + "documentary frame" border = premium feel
5. **Data viz upgrade** — numbers sirf text nahi; animated bar/counter (e.g., "74 DAYS" counter chalta hua)

### 2.2 Sound Design Upgrade (sabse sasta competitive edge)
1. **4-layer audio** (original 2-3 layer): VO + music + SFX + **texture bed** (room tone, vinyl, wind)
2. **Signature sound logo** — 0.5s sonic branding (e.g., deep "vault boom") har video ke hook mein
3. **Binaural/width** — ambience ko stereo wide karo, VO mono center = depth
4. **Silence discipline** — twist se pehle 0.2-0.3s absolute silence (original mein subtle hai; tum obvious karo)
5. **Music edits** — stock music ke stems lo (drums/bass separate) taaki beat drop exact twist par ho

### 2.3 Retention Engineering (Editing-Level)
1. **Pattern interrupt calendar** — har 8-12s visual grammar change (footage → graphic → text → diagram)
2. **Open loop stacking** — ek loop band hone se pehle doosra kholo ("...but that wasn't even the crazy part")
3. **Progress feel** — long-form mein chapter progress bar ("Part 3/5") on-screen = completion drive
4. **Visual payoff on numbers** — har number par motion (count-up, scale pop)
5. **Loop engineering (Shorts)** — last frame = first frame mirrored + spoken echo word = re-watch rate ↑ (feed mein loop = watch time double)

## 7. Risk Management (AI Content Ke Liye)

1. **"Made with AI" label** hamesha ON (policy + trust)
2. **Deepfake/real-person voice kabhi nahi** (Salk jaisi quotes = narration mein bolo, voice clone nahi)
3. **Sources description mein** — copyright-safe stock/AI visuals only
4. **Music license track rakho** (Epidemic/Artlist) — claim nahi chahiye
5. **Sensitivity:** disease/disaster topics mein factual + respectful tone (fear-mongering nahi)
